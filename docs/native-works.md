# HF 原生作品目录

## 目标

运行任务仍然由 Modal Volume、控制器及 Outbox 恢复。作品展示只读取 HF Bucket，
不需要本地全局 catalog、媒体映射表或重新下载媒体。现有任务和旧资产地址不重写。

## 文件布局

```text
works/
  029-landscape--<frozen-plan-sha256>/
    task.json
    001/
      source.png
      source.preview.webp
      edit.png
      edit.preview.webp
    002/
      video.mp4
      video.poster.webp
```

work ID 由完整冻结计划确定，前缀便于人读，后缀避免不同运行定义互相覆盖。
任务定义沿用编译后的实际步骤、提示词、seed、参数，不是媒体清单，也不是可直接
重放的任务输入。导入文件路径、Volume locator、服务配置和运行状态不公开。
公开 HF Bucket 的 task.json 会公开提示词及生成参数；不能在提示词中写秘密。
工作目录采用不可变运行定义；要为新格式作品追加不同步骤，请注册新的 task/scene。
旧格式的场景追加语义不变。

CPU 归档 worker 先发布经过 SHA-256 验证的 task.json，再使用确定性目标路径
上传并验证原件，随后独立交付同目录预览。预览失败不撤销原件。显式的 adaptive
lossless 策略仍可使用，但不允许一个步骤出现两种原件后缀。默认保持原件。
原有 outbox intent/receipt 仍是执行恢复依据，不作为画廊索引。

## Studio

用本地 Studio HTTP 服务启动，不需要下载全局文件列表。
GET /api/works 非递归读取配置 bucket 的 works/ 目录。
GET /api/works/<id> 只枚举指定作品，读取该作品 task.json 并根据实际文件生成
临时页面数据。目录存在不代表 GPU 已完成；没有预览使用原图，视频没有封面仍可播放。
默认只列作品名称，打开时才读取详情；只有显式点击所有画面才遍历全部作品。
浏览器不接收 HF token。重新编辑需要已有可信的 Volume 原件引用，跨设备只保证浏览。
当前只自动浏览配置的一个公开 bucket；其他 bucket 的旧式本地记录暂时保留。

## 兼容及迁移

未迁移旧作品仍走旧展示入口。新作品不写入旧的全局 Studio JS 媒体目录；
本地任务监控继续读取本地运行记录。历史迁移前不删除旧文件、旧回执及旧工具。
旧的直接批量输出脚本仍使用现有契约，不自动切换历史资产。

下一轮可先查看迁移计划（不会上传或删除）：

```powershell
uv run python -m tools.migrate_native_works .runtime/tasks/029-minimax-vllm-landscape-9-pairs-retry/001-main
```

在验证新部署与浏览器后，可显式加 --apply。只复制已有已验证的正式任务回执，
通过 HF 服务端 Xet copy 创建新地址，并流式校验源及目标。不重新生成、不删除旧地址。
尚缺回执的步骤保留为缺失。迁移不覆盖不匹配内容。旧 direct-results 和其他未登记
历史媒体不属于本工具的自动迁移范围，应另行审计。迁移期间旧馆藏与新目录可能并存。

## 补充验收：历史单镜头试迁移

先离线生成一个镜头的迁移计划，不执行任何云端写入：

    uv run python -m tools.migrate_native_works .runtime/tasks/029-minimax-vllm-landscape-9-pairs-retry/001-main --item 001

确认复制目标及原始回执后再显式加 --apply。试迁移保留完整任务定义，
只复制选中镜头的已归档原件及通过验证的预览。后续移除 --item 可继续全量迁移。
不要删除旧路径或在迁移验证前移除旧展示入口。

新增专项用例覆盖新旧意图共存、完整任务定义一次写入、缺失定义退避、
同槽原件冲突、同目录图片及视频衍生文件、无本地记录浏览、试迁移及复制丢失回执。
本次修改只写入代码和用例，未执行测试、构建、迁移或部署。

## Studio 展示边界

原生目录和旧版兼容媒体分别保存在前端临时内存中，合并展示时只对完全相同的原生
URL 或资产 ID 去重。相同 SHA-256 的不同镜头不合并；尚未验收迁移的不同旧地址也
不会被自动隐藏。成功刷新 HF 目录保留已加载的作品摘要，移除不再存在的原生作品；
网络错误不清空已读作品。重复的全部作品加载请求共享同一个在途操作。

旧版兼容目录在收集阶段跳过配置 Bucket 的原生媒体，仍返回本地任务摘要。静态
监控 Feed 保留原生任务摘要，但不复制原生媒体。远程作品只有匹配冻结计划身份的
本地任务才提供监控链接，编辑来源还须匹配已归档回执和原件大小、SHA-256。
无本地记录仍可以浏览，未通过历史迁移验收前不移除旧路径。
