# 003《停雨信号》｜导演分镜设计 V1.0

> 原创 2D 动画短片；人物年龄：沈雾 19 岁，周既白 20 岁。预计约 3 分钟。当前为静帧分镜任务，不宣称已经生成动画或保证 MOSS 角色一致性。

## 核心命题
能看见别人未说出口的话的沈雾，在离开小城的一天里遇见了习惯把心里话说出口的周既白。她从观察他人心声，学会真正询问与倾听。结局不挽留，分别之后继续走向自己选择的人生。

## 角色连续性
- **沈雾（19）**：中国青年女性，自然成熟面部比例，深棕色及肩微卷发和薄刘海、暖棕眼睛、浅灰绿宽松连帽外套、奶油白上衣、深炭色长裙、米白耳罩式耳机、旧黑色双肩包。橄榄绿色小行李箱贯穿四幕。第三幕摘下耳机并放在桌上；第四幕耳机放在膝上。
- **周既白（20）**：中国青年男性，真实青年成熟比例，微乱黑色短发、深色眼睛、米白色短袖亚麻衬衫、深炭长裤、褪色深色帆布单肩包。温柔克制，避免偶像式过度摆拍。
- **奇幻法则**：雨天可见「没说出口的心声」化作微小自然异象，不是文字或数字粒子。男主第一次产生犹豫时，仅一片**金色叶子**出现；它最后落在木桌上。片尾手心的叶子是真实绿色叶片，没有魔法光。
- **美术原则**：同一手绘二维动画媒介，但每幕有自己的光线、明暗、空间和色彩。避免每张都放绣球花、都逆光、都在绿色树林里。不要赛博朋克、霓虹或科技 UI。强制角色与服装锚点不代表纯文生图可完全复现脸部。

## 分镜与生成注意
1. MOSS 仅生成静态图像。Prompt 每张单独描述可见的一个瞬间，不写相机移动或时间连续动作；运镜与剪辑写在本导演稿。
2. 普通图像采用 Caption，不需要 Layout；用户若要精准定位多人物，可针对单个镜头再生成 Layout。
3. 每幕有独立任务 JSON；先 Deploy MOSS App，再通过登录的 Modal SDK 批量执行，不需要 HTTP Proxy Token。
4. 同一个场次内编号从 001 开始，输出路径是 `outputs/003-stop-rain/<scene>/001.png` 等。
5. 不要因为修改 Prompt 就直接覆盖已生成镜头：先审阅既有签名、manifest 和输出，必要时建立新版项目/场次。
6. 先对角色和不同光线测试小批量，再进行全量生成，避免一次生成 26 张后才发现人物外观不一致。
